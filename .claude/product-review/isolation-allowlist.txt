# CLAUDE.md: "Do not write documentation, comments or UI copy that implies isolation the project
# does not have." Gate G5 in scripts/review.sh finds every occurrence of sandbox / isolat* /
# virtual machine / container in README.md, docs/SPEC.md and the UI, and fails on any it cannot
# find here. This file is therefore a record of judgements, not a mute list: each row says why
# that occurrence is not an overclaim, and a reviewer should be able to disagree with the reason.
#
# Format:  <substring of the matching line> TAB <reason>
# Blank lines and lines starting with # are ignored. Match is on the whole "file:line:content"
# string, so a substring of the prose is the stable choice - line numbers move, sentences do not.
#
# When you legitimately change one of these sentences the gate fails, and the fix is to update
# the row. That upkeep is the price of the ratchet. Deleting a row you have not read is the one
# way to use this file wrongly.
