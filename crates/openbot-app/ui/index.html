OPENBOT

Your Bots live in a runtime you run yourself. Point this window at one; the defaults match openbot up on this machine.

Model

Unremembered, the key goes to the runtime this window starts and nowhere else, so you would type it again next launch. Remembered, it joins your other credentials in secrets.json, readable only by you. Either way config.toml records the variable's name and never its value, so a key cannot end up in a backup or a screen share — and an exported XAI_API_KEY still wins over a remembered one. A model on this computer needs no key and no account, and nothing leaves the machine. Start it with ollama serve, and put one of the names ollama list prints in the model field — the one filled in above is only a common small default.
